# Briefs

Finished pages for you to read, opened in your web browser.

## File names

- `Daily-Brief.html` - always the latest daily brief. Open this one.
- `YYYY-MM-DD Daily Brief.html` - a dated copy of each day's brief.
- `YYYY-MM-DD Inbox Review.html` - an inbox review with reply drafts.
- `YYYY-MM-DD Draft - [Name].txt` - an email draft, only when your mail can't hold drafts itself.
