Troubleshooting

Find the problem, try the fix. First try: ask the assistant itself what went wrong.

The assistant can't see my folder

Add the folder to the chat (the + button, or the folder option in a new task), then type set me up. Any folder works; an empty one such as Documents/My Assistant is fine. The assistant copies its files there the first time.

Email or calendar isn't connected

Open Customize, then Connectors, and connect Gmail and Google Calendar, or Outlook / Microsoft 365. Setup keeps going without them and tells you what's missing. On a Team or Enterprise plan, an admin may need to turn a connector on first.

It keeps asking for permission

Set the chat's permission menu to Auto, or choose Always allow when a prompt appears. The assistant only reads, writes files in your folder, and creates email drafts. It never sends anything.

The Daily Brief didn't run

The scheduled task runs weekdays at 8:00 AM only while the Claude desktop app is open and the computer is awake, and the folder must stay where it was. Check Scheduled in the sidebar for a task named Daily Brief. If it missed a morning, type run my daily brief.

A draft doesn't sound like me

Tell the assistant what's off (greeting, sign-off, length, a phrase you never use). It saves the rule in About-Me.md under "How I like things" and uses it from then on.

I edited a workflow and an update replaced it

"Update my assistant" refreshes CLAUDE.md and Workflows/ from the plugin. Your profile, people, meetings and briefs are never touched. Put personal rules in About-Me.md under "How I like things"; they override the defaults and survive updates.
