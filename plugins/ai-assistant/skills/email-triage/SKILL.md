name: email-triage
description: Sort recent email into what needs a reply and draft replies for the user to review. Drafts only, never sent. Use for "go through my inbox", "what needs a reply?", or "draft replies".
---

The assistant's instructions are plain files in the user's assistant folder (the folder added to this chat, or the current working directory).

1. Read `CLAUDE.md` in the assistant folder in full. It is the map and the rules.
2. Follow `Workflows/Email-Triage.md` in that folder.

If the folder has no `CLAUDE.md` yet, say so in one line and run this plugin's setup skill first.

Rule 1 of CLAUDE.md always holds: read freely, draft freely, and never send an email, post, delete, buy, message anyone, or change a calendar event unless the user approves that exact action.
